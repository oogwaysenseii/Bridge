# Feature Modules

Empty at Phase 1 by design. Feature modules (`feed`, `marketplace`, `chat`,
`notifications`, `search`) are built starting Phase 3 per docs/roadmap.md,
each owning `api/`, `services/`, `repositories/`, `validation/` — see
docs/architecture.md §3 for the folder convention every module follows.

Do not add module code here ahead of its phase — see Development Rule 5
("build one phase at a time") in the project's operating rules.
